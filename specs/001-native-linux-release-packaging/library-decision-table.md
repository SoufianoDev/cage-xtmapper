The workflow records file, readelf --program-headers, readelf --dynamic, readelf --version-info, controlled ldd resolution/transitive closure, Meson dependency/build-option introspection, Ninja link commands, build-info/provenance/manifest and checksums. The audit fails if RPATH/RUNPATH is present, loader resolution fails, or any required library is reported as not found.
